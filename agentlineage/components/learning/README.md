# AgentLineage Learning

Version 0.1.0a10. Python 3.12+. Depends on AgentLineage Core 0.1.0a10.
CLI: `agentlineage-learning --data-dir PATH --help`.
Public SDK: `agentlineage_learning.api.Learning`; execution protocol:
`agentlineage_learning.worker.Executor`.
Includes evidence-bound case packaging, versioned memory, lexical retrieval, HTTP,
budgeted draft investigation and versioned instruction assets.
Mechanical validity never certifies semantic correctness. Model execution is explicit;
memory publication is a separate operation and HTTP credential.
