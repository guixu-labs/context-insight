# 七项组件化判定：0.1.0 alpha

判定对象是 Core、Learning 两个组件；仓库是组件集，DSH 是单独交付的宿主适配。
“可安装”与“已在第二个产品稳定复用”分别记账。

| 检查项 | Core | Learning | 证据及尚欠项 |
|---|---|---|---|
| 1 独立版本 | 已具备 | 已具备 | 各自 pyproject.toml 与 capabilities；当前均 0.1.0a9，可独立规划版本 |
| 2 独立编译/打包 | 已具备 | 已具备 | 独立 wheel/sdist；Learning 声明依赖固定 Core 包，不读取宿主目录 |
| 3 独立测试 | 已验证首版 | 已验证首版 | pytest 的原生证据与记忆/作业测试；全新 venv 安装；无需宿主或模型账户 |
| 4 独立部署/重启/升级 | 进程与持久化已具备 | 进程与持久化已具备 | 分开 CLI 服务、端口和存储；重启行为有测试；Core a1→a2 真实 wheel 升级后快照 ID 与原件 SHA 保持一致；Learning 数据升级与容器实跑未验收 |
| 5 第二产品真实复用 | HarnessCore 接入已验证 | HarnessCore 调查接口/UI 已接入 | 已安装 wheel 的独立进程通过 HarnessCore 网关与实际 Agent Run 页面；材料为合成记录。Learning HTTP 调查为可控执行器测试，实际模型质量与第二团队生产使用尚未验收 |
| 6 单一职责 | 边界成立 | 边界成立 | Core 管证据；Learning 管证据上的经验生命周期；不包含迁移执行、设备验证或 Skills 自动部署 |
| 7 依赖方向干净 | 已静态验证 | 已静态验证 | AST 检查禁止宿主/反向导入；Learning 仅使用 Core 公共 API；DSH 只调 HTTP |

Core 与 Learning 是组件候选的可交付首版，尚不能以七项全绿对外宣称成熟组件。
DSH 插件具备版本、TypeScript 构建、tarball 和 SDK 级测试；完整宿主安装/卸载、真实任务验收待做。

组件生命周期：固定版本安装 → 持久卷运行 → 停服务备份 → 换已验证版本 → 检查 capabilities/契约 → 恢复服务。
本次数据库新增返修表；Core a1→a2 的既有快照回读已通过，但不是任意版本迁移或降级兼容保证。未知格式或未知内核版本应先在副本验证，不能覆盖老库后宣称可回滚。
学习作业遇到进程重启进入 interrupted；已发出且尚未取回用量的调用禁止直接 resume。
发布库的 .publish.lock 不自动删除；若持锁进程崩溃，需核实没有活动发布者并对照 HEAD/snapshot 后人工恢复。
